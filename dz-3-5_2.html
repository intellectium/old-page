1. В условии можно считать

Сначала Python считает, потом сравнивает. Номер автобуса красивый, если обе цифры одинаковые:

n = int(input())
if n // 10 == n % 10:
    print('красивый')
else:
    print('обычный')

2. В ветке можно печатать число

Заказ от 500 рублей — доставка бесплатно, иначе плюс 100 рублей:

n = int(input())
if n >= 500:
    print(n)
else:
    print(n + 100)

Слово — в кавычках, переменная и число — без кавычек. print('n') напечатает букву n, а не число.

3. Три исхода: elif

elif — «иначе если». Когда исходов три, одного else мало:

a = int(input())
b = int(input())
if a > b:
    print('победа')
elif a < b:
    print('поражение')
else:
    print('ничья')
  1. Условия проверяются сверху вниз, срабатывает первое верное.
  2. elif — только после if и до else. else — один, последним, без условия.
  3. Двоеточие — после каждого условия и после else.

4. Слова — точно как в условии

Проверка посимвольная: маленькие буквы, без точки, пробел там же, где в условии. «не хватит» и «нехватит» — разные ответы.

1. Цифры числа

Остаток от деления на 10 — последняя цифра. Целая часть от деления на 10 — число без последней цифры.

print(47 % 10)    # 7
print(47 // 10)   # 4

С сотнями так же, только делим на 100. Ноль впереди не печатается:

print(214 // 100)   # 2
print(214 % 100)    # 14
print(305 % 100)    # 5

2. Первый if

Программа сама выбирает, что напечатать. Если условие верно — выполняется то, что под if. Иначе — то, что под else.

n = int(input())
if n % 2 == 0:
    print('чётное')
else:
    print('нечётное')

Три правила:

  1. После условия и после else — двоеточие.
  2. Команды внутри if и else сдвинуты вправо (4 пробела или Tab).
  3. «Равно?» пишется двумя знаками: ==. Одно = — это «запомни в переменную».

3. Знаки сравнения

ЗнакВопрос
==равно?
!=не равно?
>больше?
<меньше?
>=больше или равно?
<=меньше или равно?

«Не больше 4» — это <= 4: четыре тоже подходит. «Хватит, если денег ровно на билет» — это >=.

4. Слова — точно как в условии

Проверка посимвольная: маленькие буквы, без точки, пробел там же, где в условии. «не хватит» и «нехватит» — разные ответы.

1. Текст — это ещё не число

input() всегда отдаёт текст, даже если человек набрал одни цифры. А для текста знак + значит «приклеить»:

a = input()
b = input()
print(a + b)

Ввели «3», потом «4» — на экране 34, а не 7. Python не ошибся: он приклеил «4» к «3», как два слова.

Сравни:

print('3' + '4')    # 34
print(3 + 4)        # 7

В кавычках — текст, без кавычек — число.

2. int() — превратить текст в число

int() говорит Python: «здесь число, считай по-настоящему». Оборачиваем в него input():

a = int(input())
b = int(input())
print(a + b)

Тот же ввод «3», «4» — теперь на экране 7.

Читаем изнутри наружу: сначала input() спрашивает и получает текст, потом int() превращает текст в число, потом число кладётся в коробку a. Не забудь закрыть обе скобки: int(input()).

3. Пять действий (и ещё одно)

4. // и % — две половинки одного деления

17 конфет раскладываем по 5 в пакет:

  • полных пакетов — 17 // 5, это 3;
  • конфет осталось — 17 % 5, это 2.

Проверка: 3 пакета по 5 — это 15, и ещё 2 — всего 17. Значит, // — сколько целых раз, % — сколько осталось.

Если делится без остатка, остаток — ноль. Ноль тоже нужно напечатать.

5. / печатает число с точкой

Обычное деление / всегда печатает число с точкой — даже если делится нацело:

print(9 / 4)      # 2.25
print(8 / 2)      # 4.0

4.0 и 4 для проверки — разные ответы. Нужно целое — бери //.

6. Два числа в одной строке — split()

Иногда оба числа приходят одной строкой через пробел: «7 5». Тогда int(input()) не сработает: в тексте «7 5» есть пробел, а это не число.

Сначала строку режем по пробелу — это делает split():

a, b = input().split()
a = int(a)
b = int(b)
print(a + b)

Ввели «7 5» — на экране 12.

  • input().split() режет строку «7 5» на два куска: «7» и «5».
  • a, b = … раскладывает куски по двум коробкам: первый — в a, второй — в b.
  • Куски всё ещё текст, поэтому каждый превращаем в число своим int().

7. Как понять, как читать числа

Смотри на пример ввода в условии:

  • числа на разных строках («7, потом 5») — каждое своим int(input());
  • числа в одной строке через пробел («7 5») — split().

Задач: 6. Обязательные — 4, по желанию ★ — 2.

Математическая задача («Пять кружек на полке») здесь не идёт — она на бумаге в Домашнем задании, с доказательством.
Памятка: что было на уроке

Если что-то забылось — здесь всё, что было на занятии, с примерами. Прочитай перед задачами: решать тут ничего не надо.

1. Вспомним: input и коробки

input() спрашивает, а ответ кладём в коробку-переменную:

a = input()
b = input()

Первый input() получает первый ответ, второй — второй. Программа всегда идёт сверху вниз.

2. Порядок печати выбираешь ты

Порядок input() задаёт условие — в каком порядке программа получает ответы. А порядок print — твой выбор. Коробки уже заполнены, печатай их как нужно:

a = input()
b = input()
print(b)
print(a)

Ввели «утро», потом «вечер» — на экране сначала вечер, потом утро.

Как не запутаться: подпиши себе, что лежит в каждой коробке. Например, для «Порядка уроков»: в a — первый урок, в b — второй, в c — третий. Условие просит «третий, первый, второй» — значит print(c), print(a), print(b).

3. Не всё прочитанное надо печатать

Если условие говорит «спроси три слова, напечатай первое и третье», второе всё равно нужно прочитать — иначе третий ответ попадёт не в ту коробку. Просто его коробку не печатаем:

a = input()
b = input()
c = input()
print(a)
print(c)

4. Два значения в одной строке

Если в одном print два значения через запятую — они печатаются в одну строку через пробел:

name = input()
surname = input()
print(surname, name)

Ввели «Марк», потом «Орлов» — на экране Орлов Марк.

5. end — склеить два print в одну строку

Обычно каждый print заканчивается переходом на новую строку. end меняет то, что стоит в конце: тогда следующий print допишется в ту же строку, прямо следом.

a = input()
b = input()
print(a, end=' и ')
print(b)

Ввели «хлеб», потом «молоко» — на экране одна строка: хлеб и молоко.

Пробелы вокруг «и» мы написали сами, внутри кавычек. Без них слова слипнутся: хлебимолоко.

6. sep и end вместе

  • sep — что ставится между значениями одного print;
  • end — что ставится после всех значений, вместо перехода на новую строку.
a = input()
b = input()
c = input()
print(a, b, sep=', ', end=' и ')
print(c)

Ввели «хлеб», «молоко», «сыр» — на экране хлеб, молоко и сыр.

По шагам: первый print печатает «хлеб, молоко» (между ними sep), потом вместо новой строки — « и » (это end), а второй print дописывает «сыр».

Сравни разные sep:

print('хлеб', 'молоко', sep=', ')
print('хлеб', 'молоко', sep=',')

Первая строка: хлеб, молоко — с пробелом. Вторая: хлеб,молоко — без пробела. Для проверки это разные ответы.

7. Точка в конце строки

Чтобы строка закончилась точкой, а не переходом на новую строку, ставим end='.':

print('раз', 'два', 'три', sep='; ', end='.')

На экране: раз; два; три.

8. Кавычки решают

Значения sep и end — это текст, поэтому пишутся в кавычках: end=' и ', а не end=и. Без кавычек Python решит, что «и» — имя коробки, которой нет, и программа остановится с ошибкой NameError.

Памятка: что было на уроке

Если что-то забылось — здесь всё, что было на занятии, с примерами. Прочитай перед задачами: решать тут ничего не надо.

1. Вспомним print

print печатает то, что стоит в скобках. Текст пишется в кавычках. Несколько значений через запятую печатаются через пробел:

print('Привет,', 'мир')

На экране: Привет, мир — пробел между словами поставил сам print.

2. input — программа спрашивает

input() останавливает программу и ждёт, пока человек напечатает ответ и нажмёт Enter. Пока ответа нет — программа стоит и ждёт.

То, что напечатали, input() отдаёт программе. Но если ответ никуда не положить, он сразу потеряется.

3. Переменная — коробка с именем

Чтобы ответ не потерялся, кладём его в переменную — коробку с именем:

name = input()

Читается так: «спроси и положи ответ в коробку name». Знак = здесь значит не «равно», а «положи в коробку».

Дальше вместо ответа пишем имя коробки:

name = input()
print('Привет,', name)

Если ввели «Аня», на экране будет Привет, Аня. Программа одна и та же, а ответ у каждого свой: введёт Марк — получится Привет, Марк.

4. Несколько коробок

Каждый ответ — в свою коробку, своим input():

name = input()
city = input()
print('Имя:', name)
print('Город:', city)

Если ввели «Аня», потом «Псков» — на экране:

Имя: Аня
Город: Псков

Первый input() получает первый ответ, второй — второй. Программа идёт строго сверху вниз.

5. Печатать можно в любом порядке

Коробки уже заполнены — значит, их можно печатать в каком угодно порядке:

first = input()
second = input()
print(second)
print(first)

Ввели «утро», потом «вечер» — на экране сначала вечер, потом утро.

А ещё не всё прочитанное обязательно печатать: коробка может просто полежать.

6. Имена коробок

  • латинскими буквами: name, city, word;
  • без пробелов;
  • с маленькой буквы.

7. Кавычки решают

print('name')

напечатает само слово name — буквы в кавычках. А

print(name)

напечатает то, что лежит в коробке. Нужен ответ человека — пиши имя коробки без кавычек.

8. sep — что ставить между значениями

print ставит между значениями пробел. sep меняет этот пробел на что угодно:

print('Аня', 'Математика', sep='-')

На экране: Аня-Математика. А sep='' — пустые кавычки — значит «ничего не ставить»:

name = input()
print('Привет, ', name, '!', sep='')

Если ввели «Аня» — Привет, Аня!, без пробела перед «!». Пробел после запятой мы написали сами, внутри кавычек.

9. Важно: в input() ничего не пиши в скобках

Проверка сравнивает весь вывод программы буква в букву с примером. Если написать в скобках input('Как тебя зовут?'), этот вопрос тоже напечатается — и получится лишний текст.

Занятие 1 · print, sep и end

Задач: 8. Обязательные — 5, по желанию ★ — 3.

Логическая задача (с отрицаниями, как «Кружки» на уроке) здесь не идёт — она на бумаге в Домашнем задании.
Памятка: что было на уроке

Если что-то забылось — здесь всё, что было на занятии, с примерами. Прочитай перед задачами: решать тут ничего не надо.

1. Компьютер делает ровно то, что сказано

Помнишь игру «Ты — командир, я — компьютер»? Компьютер не догадывается, что ты имел в виду. Он делает ровно то, что написано, слово в слово. И выполняет команды строго сверху вниз, по одной.

2. print — напечатай

print('Привет')

Из чего сделана эта строка:

  • print — «напечатай»;
  • скобки ( ) — «вот что печатать»;
  • кавычки ' ' — «это текст, напечатай его как есть».

На экране будет Привет — без кавычек. Кавычки нужны компьютеру, а не человеку.

3. Каждый print — с новой строки

print('Привет')
print('Идём дальше')

На экране две строки: сначала «Привет», под ним «Идём дальше». Как написано сверху вниз — так и напечатается.

4. Где на клавиатуре

  • ( — Shift + 9, ) — Shift + 0;
  • кавычка ' — клавиша Э в английской раскладке.

Нужны прямые кавычки ' '. Ёлочки « » Python не понимает.

5. Несколько значений в одном print

В скобках можно написать несколько текстов через запятую. print напечатает их в одну строку и сам поставит между ними пробел:

print('7', '4', '1')

На экране: 7 4 1.

6. sep — что ставить между значениями

sep (читается «сеп», от слова «разделитель») говорит, что ставить между значениями вместо пробела:

print('7', '4', '1', sep='-')     # 7-4-1
print('7', '4', '1', sep='')      # 741

sep='' — две кавычки подряд, между ними ничего. Это значит «не ставь ничего». Это не ошибка!

7. end — что ставить в конце

Каждый print в конце сам ставит «невидимый Enter» — поэтому следующий print начинается с новой строки. end говорит, что поставить в конце вместо этого Enter:

print('раз', end=' ')
print('два')

На экране одна строка: раз два. А вот что получается с разными end:

ПрограммаНа экране
print('раз') и print('два')две строки: раз, два
print('раз', end=' ') и print('два')раз два
print('раз', end='') и print('два')раздва
print('раз', end='!') и print('два')раз!два

8. Как писать sep и end

  • Сначала всё, что печатаем, потом настройки: print('7', '4', '1', sep='-').
  • sep и end — маленькими буквами, без кавычек. А то, что в них ставим, — в кавычках: sep='-'.
  • Можно обе сразу: print('7', '4', '1', sep='-', end='!') печатает 7-4-1!.

9. Красный текст — компьютер объясняет, чего не понял

Пустой экран хуже красной ошибки. Увидел красный текст — сначала посмотри сам:

  1. Последняя строка — что случилось.

10. Перед тем как нажать «Проверить»
